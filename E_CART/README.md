# A Simple Shopping Cart 
A very simple shopping cart where you can: 
- view the product list
- view the cart 
- add products to cart
- remove products from cart
- clear cart
- checkout 

### Skills Gained:
- conditional statements
- while and for loops
- dictionaries
- functions 
- try-except blocks
